# Overnight QA — 2026-09-11

Browser QA of the features that landed after the 2026-09-10 production QA: the canvas
quality-of-life round (`6259a4e`), the node-settings redesign (`d148dc4`), the landing page, and
the surfaces around them. Driven through Chrome against the local dev servers (`web` :3000, `api`
:3001, `runtime` :3002, `landing` :3004) with the owner's account on the shared database. Every
flow, table, secret and API key created for this run was deleted afterwards.

## Fixed and pushed

Severity is the effect on someone using the product.

**1. HIGH — Marketplace detail pages crashed.** `/marketplace/[slug]` showed "This page could not
load". The read-only preview draws the builder's node cards, and the inline rename from the canvas
round made `NodeLabel` read the builder store, which the preview never provides. Node and group
labels now read an inert store when there is no provider (`d9a39b5`). Verified on production after
the deploy.

**2. Applying an AI edit dropped every group frame.** The model never sees frames, so its answer
replaced the document and the frames vanished. `applyDocument` takes `keepGroups`: a frame whose
nodes survive is carried over, refitted around where they are now, and the AI panel asks for it
(`09ee73a`).

**3. The frame settings panel rendered unstyled** — no header, padding or type — because it still
used classes the redesign moved into `node-settings.module.css` (`879556a`).

**4. A run error on a branch card (if/else, switch, filter) overlapped the True/False tabs** and ran
past the card's edge; it is a row of its own now (`0a3d660`).

**5. ⌘K had no keyboard selection.** Nothing was active after typing, and Down/Enter did nothing;
only a click worked. It now behaves like the node picker: first match active, arrows move, Enter
runs (`4bbb656`).

## Open

- **A deep link is lost through login.** (fixed) Opening `/marketplace/<slug>` (or any workspace
  URL) signed out landed on `/flows` after sign-in, because the login form always replaced to
  `/flows`. A `redirects()` rule in `next.config.ts` now sends a page opened without the session
  cookie to `/login?next=<path>`, the login form keeps a same-origin path in session storage, and
  sign-in or onboarding returns to it (after a waiting landing-page prompt, before `/flows`). The
  query string is not carried, so `/flows/<id>?run=<id>` returns to the flow without its run.
- **Unreproduced:** once, a frame shrank from 300 to 260 tall after a node was dragged just below
  its bottom edge; undo showed it as a separate resize entry, so the drag most likely started on
  the resizer's bottom line. Later drags behaved.
