# UI Lab

Local component previews using `@automator/ui`. Sidebar code stays in this app.

Run `bun run dev --filter=@automator/ui-lab` from the repository root.
Open http://localhost:3003. No environment file or backend is needed.

In development, Agentation appears in the bottom-right corner. Activate it,
select an element, add a note, and copy the feedback into the coding conversation.
It runs locally without Agent Sync or a webhook and is excluded from production.
